# Background Image for Rain Ultra Effect

This folder should contain a background image for the ultra-realistic rain effect.

## Required File

`bg.jpg` — A dark, moody background image (city night, window view, etc.)

## Recommended Specs

- Resolution: 1080x1920 (or similar portrait ratio)
- Style: Dark, atmospheric (night scene, rainy city, foggy)
- Format: JPG or PNG

## Example Sources

- Unsplash (search "rain window", "city night", "moody")
- Pexels
- Your own photos

## Usage

The `RainUltra` widget will:
1. Load this image as background
2. Apply glass refraction distortion
3. Create the "looking through wet window" effect
